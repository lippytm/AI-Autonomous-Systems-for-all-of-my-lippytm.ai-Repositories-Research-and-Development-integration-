## How Every Repo Connects to the Swarm

Each repository connects to the Hermes/Fabric swarm through three standard integration points:

### 1. Hermes Subscription
Every repo registers its **topic subscriptions** — which message types it listens for:
```yaml
repo: lippytm/Chatlippytm.ai.Bots
subscribe:
  - swarm.tasks.chat
  - swarm.memory
  - swarm.health
  - code.tasks.python
publish:
  - swarm.results
  - swarm.errors
```

### 2. Fabric Environment Profile
Every repo declares its **execution environments** — what tools it can run:
```yaml
repo: lippytm/Web3AI
environments:
  - code_runner.python
  - blockchain_connector.ethereum
  - blockchain_connector.hyperledger
  - api_caller.web3
```

### 3. Clone Identity Declaration
Every repo declares its **active clone identity**:
```yaml
repo: lippytm/Evolutionary-Evolutions-Social-Multimedia-Networks-Agency-
primary_identity: Lippy Killjoy
secondary_identity: lippytmai
voice: bold, creative, culturally disruptive
```
