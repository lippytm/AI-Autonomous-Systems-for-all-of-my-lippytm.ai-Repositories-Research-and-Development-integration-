## OPERATING MODEL

### Engineer Manager Responsibilities
- Convert goals into repo-ready workstreams
- Define ownership across agents and systems
- Sequence technical work in a logical order
- Protect quality, maintainability, and continuity
- Escalate blockers before they become delays

### Communications Manager Responsibilities
- Publish concise updates for progress, decisions, and risks
- Keep message formats consistent across repos
- Translate technical details for non-technical audiences when needed
- Preserve institutional memory in documentation
- Maintain continuity between planning, execution, and review
